# dsh-1c-project-properties v0.2.0

## Новое

- **Выгрузка конфигурации в файлы** — кнопка «Выгрузить конфигурацию в файлы» в карточке проекта. Запускает Конфигуратор 1С в пакетном режиме (`DESIGNER /DumpConfigToFiles`) и складывает XML в папку проекта: `Configuration.xml`, `ConfigDumpInfo.xml`, каталоги объектов. Формат выгрузки — иерархический или плоский; режим `-update` выгружает только изменившиеся объекты; отдельная галочка снимает lock-файлы `.cfl` перед запуском.
- **Прогресс и лог в той же вкладке** — состояние, прошедшее время, число выгруженных файлов, версия конфигурации (из `<Version>` в `Configuration.xml`) и вывод Конфигуратора. Выгрузку можно отменить; одновременно идёт только одна (Конфигуратор блокирует конфигурацию базы, повторный запуск получает 409).
- **Новые параметры проекта** — `unlockCode` (код доступа к базе, `/UC`) и `dumpDir` (каталог выгрузки; пусто = корень проекта).
- **Новые роуты** — `POST /1cprops/dump-start`, `GET /1cprops/dump-status`, `POST /1cprops/dump-cancel`.

## Прочее

- Успех выгрузки определяется по `/DumpResult` (0 — успех, 1 — ошибка) и по числу появившихся файлов: код возврата 1С отдаёт 0 и при провале.
- Если `-update` запрошен, а `ConfigDumpInfo.xml` в каталоге нет, плагин делает полную выгрузку и пишет об этом в лог — у Конфигуратора это ошибка, `-force` её не закрывает.
- Путь к платформе принимается и файлом (`1cv8.exe`), и каталогом (`bin`): во втором случае exe ищется автоматически. В сессии пользователя используется `1cv8.exe` — `1cv8s.exe` там молча завершается с кодом 0 (проверено на 8.3.27.2130).
- Лимит одной выгрузки — 60 минут; по истечении процесс снимается вместе с деревом.
