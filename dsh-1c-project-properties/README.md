# dsh-1c-project-properties

Плагин DeepSeek Harness: **параметры 1С в разрезе проекта**.

Добавляет в настройки DSH вкладку **«1С: параметры»**: сверху — общие значения для машины, ниже — список проектов и форма параметров выбранного проекта. Значения проекта лежат в его собственной папке, в файле `.dsh/1c-project.json`, поэтому переезжают вместе с проектом, видны в git и доступны другим инструментам (плагинам, агентам, скриптам).

## Что хранится

На проект:

| Поле | Ключ в JSON | Смысл |
|---|---|---|
| Путь к базе | `infobasePath` | папка файловой базы либо строка соединения `Srvr="srv";Ref="base";` |
| Пользователь | `user` | имя пользователя 1С для авторизации |
| Пароль | `password` | пароль (хранится в открытом виде — см. ниже) |
| Путь к платформе | `platformPath` | `…\bin\1cv8.exe`; **пусто = берётся значение из общих настроек** |

Общие значения (на машину, для всех проектов): путь к платформе по умолчанию — файл `$DSH_HOME/1c-project-properties/settings.json` (`$DSH_HOME` — переменная окружения, иначе `~/.dsh`).

Список проектов = воркспейсы DSH из реестра + пути, добавленные вручную в этой же вкладке. Дубликаты по пути отбрасываются.

## Использование

1. **Settings → «1С: параметры»**.
2. В блоке «Общие» — путь к платформе по умолчанию.
3. Выберите проект слева (или добавьте путь вручную).
4. Заполните путь к базе, пользователя, пароль → **«Сохранить»**.

Метка ● у проекта — файл параметров есть, ○ — ещё не создан. Путь к платформе в проекте заполняется только при отличии от общего.

## Файл параметров проекта

```json
{
  "$schema": "dsh-1c-project-properties/v1",
  "infobasePath": "Srvr=\"srv-1c\";Ref=\"buh\";",
  "user": "Администратор",
  "password": "***",
  "platformPath": ""
}
```

- Путь: `<папка проекта>/.dsh/1c-project.json`, UTF-8, отступ 2.
- Запись атомарная (временный файл + переименование) — обрезанного JSON не будет.
- Плагин пишет только свои четыре ключа; посторонние ключи в файле сохраняются.
- **Пароль лежит открытым текстом** — не коммитьте файл в git.

## Установка

Требуется `dsh` ≥ 0.1.2-rc.1.

```sh
# из публичного релиза
dsh plugin --profile web add https://github.com/Mempemp/DSH-1CProjectProperties/releases/download/v0.1.0/dsh-1c-project-properties-0.1.0.tgz

# из локального архива
dsh plugin --profile web add ./dsh-1c-project-properties-0.1.0.tgz

# из папки плагина (режим разработки, правки применяются без переустановки)
dsh plugin --profile web add <путь к папке>/dsh-1c-project-properties
```

После установки — перезапуск DSH (композиция плагинов читается на старте) и жёсткая перезагрузка страницы в браузере.

Если `dsh` не в PATH (локальная установка, DSH Desktop), вызывайте точку входа через node:

```powershell
node "C:\путь\к\dsh\lib\bin.js" plugin --profile web add "C:\путь\к\dsh-1c-project-properties-0.1.0.tgz"
```

Частые сложности:

| Симптом | Что делать |
|---|---|
| `ERR_PNPM_UNEXPECTED_STORE` | добавить `--store-dir="<путь к вашему pnpm store>"` |
| `EPERM` при записи в `…\profiles\web` | нет прав на папку профиля: закрыть DSH, разрешить запись, повторить |
| Предупреждения про peer-зависимости (`cordis`, `react`, `react-dom`) | игнорировать: внешних зависимостей у плагина нет |
| Вкладки нет после установки | DSH не перезапущен либо страница не перезагружена (`Ctrl+Shift+R`) |

Проверка хост-части: `curl -s http://127.0.0.1:<порт>/1cprops/state`.

## HTTP-роуты

| Метод и путь | Назначение |
|---|---|
| `GET /1cprops/state` | общие настройки, список проектов, найденные платформы 1С |
| `POST /1cprops/common` | `{platformPath}` — сохранить общее значение |
| `POST /1cprops/project-save` | `{path, params}` — записать файл параметров проекта |
| `GET /1cprops/project?path=…` | действующие параметры проекта (общий путь к платформе подставлен) |
| `POST /1cprops/project-clear` | `{path}` — удалить файл параметров |
| `POST /1cprops/project-add` | `{path}` — добавить папку в список проектов |
| `POST /1cprops/project-forget` | `{path}` — убрать дополнительный путь из списка |

## Структура плагина

```
package.json          dsh.bundle.patch → cordis.patch.yml; dsh.client → lib/client.js
cordis.patch.yml      одна строка insert: монтирует плагин в композицию профиля
lib/index.js          хост: роуты /1cprops/*, чтение и запись JSON, поиск платформ 1С
lib/client.js         браузер: секция settings.section («1С: параметры»)
```

Хост-половина — ESM с `export { name, inject, apply }`, `inject = ["webServer", "workspaceRegistry"]`. Клиентская — модуль для `window.__ModuleLoader__` с `factory(require)` и `return { apply, inject: ["slots"] }`. Внешних зависимостей нет: только `node:*` и React из рантайма DSH.
