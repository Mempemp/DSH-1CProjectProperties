# Плейбук: поиск по коду и объектам

## Когда

- Нужен модуль по имени объекта, формы или общего модуля.
- Нужен состав объекта: реквизиты, табличные части, измерения, ресурсы,
  предопределённые элементы, макеты, формы.
- Нужны места вызова процедуры или функции, места использования объекта.
- Нужен текстовый поиск по выгрузке: строка, имя, фрагмент запроса, XML.
- Нужна инвентаризация: сколько объектов вида, какие общие модули
  привилегированные, у каких объектов есть макеты.

Правка — не здесь: чтение состава объекта этим плейбуком, изменение —
`metadata.md` и `ui.md`.

## Чем

MCP `rlm`: индекс по выгрузке. Сессия — `rlm_start`, работа — `rlm_execute`,
закрытие — `rlm_end`.

- `rlm_start(query, project, path, domains)` — `query` — вопрос словами;
  `project` — имя зарегистрированного проекта rlm; `path` — корень выгрузки, если
  проект не зарегистрирован; `domains` — что понадобится: `["код"]`,
  `["структура"]`, `["документ"]`, `["связи"]`, `["поиск"]`, `["весь каталог"]`.
  Возвращает `session_id`.
- `rlm_execute(session_id, code, domains)` — Python в сессии, вывод через `print`,
  переменные живут между вызовами; `domains` догружает подписи хелперов.
- `rlm_help(helpers=["find_module", ...])` — подпись и рецепт хелпера, если
  аргументы забыты.
- `rlm_end(session_id)` — освободить сессию.

Хелперы внутри `rlm_execute`:

| Хелпер | Аргументы | Что отдаёт |
|---|---|---|
| `find_module` | `name='', module_type='', category='', limit=50` | модули: путь, категория, объект, вид модуля, форма |
| `find_by_type` | `meta_type, name='', limit=50, count_only=False` | модули объектов вида; `count_only=True` — число |
| `find_attributes` | `name='', object_name='', category='', kind='', limit=500` | реквизиты: имя, синоним, тип, вид, ТЧ |
| `find_predefined` | `name='', object_name='', limit=500` | предопределённые элементы: имя, синоним, типы |
| `find_common_modules` | `name='', flag='', limit=200` | общие модули и их флаги (`privileged`, `global`, …) |
| `find_templates` | `owner='', name='', template_type='', limit=200` | макеты; требует индекса |
| `get_object_full_structure` | `name` | объект целиком: реквизиты, ТЧ, измерения, ресурсы, формы, макеты |
| `safe_grep` | `pattern, name_hint='', max_files=20` | строки в модулях, но не больше `max_files` модулей |
| `git_search` | `pattern, path='', file_types='', regex=False, ignore_case=False, mode='lines', max_results=200, exclude_path=''` | совпадения по всей выгрузке, если она под git |

Нативные `glob`, `grep`, `read` — когда известен точный путь или файлов мало.

## Порядок

1. Определяю вид вопроса. Состав объекта → `get_object_full_structure`; модуль →
   `find_module`; объекты вида → `find_by_type`; вызовы и строки → `safe_grep`
   или `git_search`; общий модуль и его флаги → `find_common_modules`.
2. `rlm_start` с `domains` под вопрос и `project` (или `path`) этого проекта.
3. В `rlm_execute` печатаю только нужное: путь, имя, строку. Целые структуры в
   контекст не выгружаю.
4. `safe_grep` вернул пусто или мало — срез `max_files` применяется всегда:
   сужаю `name_hint` до конкретного модуля или поднимаю `max_files`.
5. Исчерпывающий поиск по выгрузке — `git_search`, а не `safe_grep`. Упёрся в
   `truncated_by='per_file'` — сужать `path` бесполезно, нужен `exclude_path`
   или другой запрос.
6. Найденные имена методов и типов сверяю по `platform.md`, прежде чем писать код.
7. `rlm_end`.

## Если недоступно

- **`rlm_start` не отвечает (сервер не поднят).** Работаю `glob` + `grep` по
  корню выгрузки; в ответе помечаю, что поиск неполный.
- **Индекса нет или он неполный.** `find_templates` без индекса отдаёт пустой
  ответ и `source='unavailable'`; `find_attributes` и `find_predefined` без
  `object_name` — тоже пусто. Передаю `object_name` либо собираю индекс:
  `rlm_index(action="info")`, затем `rlm_index(action="build", project=...,
  confirm=<пароль>)`. Пароль спрашиваю у человека, не выдумываю.
- **Проект не зарегистрирован.** `rlm_projects(action="list")`; регистрация —
  `rlm_projects(action="add", name=..., path=...)` с паролем от человека; либо
  работаю через `path` в `rlm_start`.
- **Выгрузка не под git.** `git_search` недоступен: остаются `safe_grep` по
  конкретным модулям из `find_module` и `grep`.
