# Правила проекта

Ваши правила для агента. Плагин создаёт этот файл один раз и больше не
перезаписывает — ни при обновлении набора правил, ни при его удалении. Пишите
здесь, а не в `AGENTS.md`: тот файл собирается плагином и теряет правки.

DSH не загружает `USER-RULES.md` сам. Агент читает его по ссылке из `AGENTS.md`
в начале работы, поэтому правило, записанное здесь, действует наравне с правилами
набора.

## Как писать

- Один пункт — одно правило: что делать или чего не делать, и почему. Причина
  нужна, иначе правило отменят при первом удобном случае.
- Правило действует, пока его не отменили явно. Устаревшее — удаляйте.
- Здесь только то, что относится к этому проекту: соглашения, запреты, особые
  случаи. Общие приёмы работы — в плейбуках `.dsh/rules-own/`.
- Не дублируйте правила набора: если поведение уже задано набором, пишите только
  отличие проекта от него.
- Параметры проекта (база, пользователь, платформа, каталог выгрузки) живут в
  `.dsh/1c-project.json`; здесь их не повторяйте — они разойдутся.
