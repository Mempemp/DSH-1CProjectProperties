# dsh-1c-project-properties v0.3.0

## Новое

- **Подбор базы из штатного списка 1С.** Поле «Путь к базе» теперь подсказывает базы из `ibases.v8i` — список пользователя (`%APPDATA%\1C\1CEStart\ibases.v8i`), общий список машины (`%PROGRAMDATA%\1C\1CEStart\ibases.v8i`) и внешние списки, подключённые параметром `CommonInfoBases` в `1cestart.cfg`/`1cescmn.cfg`. Файловая база подставляется путём к папке, клиент-серверная — строкой `Srvr="…";Ref="…";`; базы через веб-сервер (`Connect=ws=…`) в список не попадают, их количество показывается в подсказке. Список отдаётся в `GET /1cprops/state` (`infobases`, `infobasesSources`).
- **Поиск платформы по `InstalledLocation`.** Кроме `%ProgramFiles%\1cv8`, `%ProgramFiles(x86)%\1cv8` и `%LOCALAPPDATA%\Programs\1cv8` каталог установки берётся из `1cestart.cfg` — это помогает при нестандартном размещении платформы.

## Прочее

- **Живой прогресс выгрузки.** Пока идёт выгрузка, число файлов в каталоге обновляется каждые 5 секунд (раньше счётчик показывал 0 до завершения). Проверено на реальной базе УТ 11.5: 11 → 4911 → 8497 → 8865 файлов, отмена снимает процессы 1С полностью.
- Конфигурационные файлы `1cestart.cfg` читаются как UTF-16LE (в этой кодировке их пишет 1С), списки `.v8i` — как UTF-8 с запасным cp1251.
