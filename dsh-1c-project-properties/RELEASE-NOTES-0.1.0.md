# dsh-1c-project-properties v0.1.0

Первый выпуск: вкладка **«1С: параметры»** в настройках DSH со списком проектов и хранением параметров 1С в папке каждого проекта.

## Возможности

- **Вкладка в настройках** — секция «1С: параметры» рядом с «Основные» и «Плагины» (слот `settings.section`).
- **Параметры проекта в его папке** — файл `.dsh/1c-project.json`: `infobasePath`, `user`, `password`, `platformPath`. Запись атомарная, посторонние ключи в файле сохраняются.
- **Общие значения** — путь к платформе по умолчанию для всей машины (`$DSH_HOME/1c-project-properties/settings.json`); поле проекта перекрывает общее значение, пустое — наследует.
- **Автопоиск платформ 1С** — сканирование `%ProgramFiles%\1cv8`, `%ProgramFiles(x86)%\1cv8`, `%LOCALAPPDATA%\Programs\1cv8`; найденные версии подставляются в поле как список автодополнения.
- **Список проектов** — воркспейсы DSH из реестра плюс пути, добавленные вручную во вкладке.
- **Роуты `/1cprops/*`** — чтение и запись значений доступны другим плагинам и агентам; `GET /1cprops/project?path=…` отдаёт действующие параметры с подставленным путём к платформе.

## Прочее

- Внешних зависимостей нет: host-часть на `node:*`, клиентская — на React из профиля DSH.
- Требуется dsh ≥ 0.1.2-rc.1 (слот `settings.section`).
- Пароль хранится в файле проекта открытым текстом — файл не следует коммитить.
