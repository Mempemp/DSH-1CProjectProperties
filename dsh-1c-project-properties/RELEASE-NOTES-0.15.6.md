# 0.15.6 — дословный справочник правил 1С

## Что добавлено

`reference/comol/` — 34 файла, 3 041 строка правил набора `ai_rules_1c` (пин `ef070d1`)
без правок, с шапкой «источник, коммит, путь» в каждом файле.

Справки их инструментов (роли, БСП, СКД, расширения, макеты, формы) в поставку не
входят: агент получил бы команды к инструментам, которых у нас нет. Работающие
факты оттуда стоят в плейбуках требованиями: состояние поддержки объекта, макет
HTML в `Ext/Template/<язык>.html` с каталогом `_files`, обычная форма в `Form.bin`
без сжатия, права на вложенных объектах, перехватчики расширения.

Внутри то, что раньше жило только в пересказе: контракт блокировок и транзакций,
каталог антипаттернов, проектирование регистров и СКД, грабли XML метаданных и
форм, пакетные проверки Конфигуратора, тест-клиент, драйвинг веб-клиента,
`getconfigfiles`, EDT-workflow, поиск по нескольким контурам.

## Как подключено

- Справочник лежит в пакете плагина: в проект не копируется, приезжает с обновлением.
- `.dsh/rules-own/environment.md` печатает путь и список файлов с заголовками.
- Каждый плейбук заканчивается блоком «Полный текст» со своими файлами.
- Шапка `AGENTS.md` говорит, когда в справочник идти.

## Перенос

`tools/port-comol-reference.mjs` — механический, без пересказа:

```sh
node tools/port-comol-reference.mjs                     # из кэша каталога
node tools/port-comol-reference.mjs --from <zip|каталог> --check
```

Берёт `content/rules` целиком, кроме 23 файлов про их рабочий процесс, модели
и MCP-серверы (список с причинами — в `SKIP`), плюс `query-writing.md` и
`query-optimization.md`. При смене пина печатает новые и исчезнувшие файлы.
