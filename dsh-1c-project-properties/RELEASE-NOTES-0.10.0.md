# 0.10.0 — карточка синтаксической индексации: честные состояния и папка выгрузки

## Автообновление больше не крутится вхолостую

Статус «устарел: структура изменилась» обновлением не лечится: `update` строит дельту по тому,
что видит git, а проверка свежести обходит все папки проекта. Любой `.bsl` в игнорируемой папке
(артефакты прогонов, фикстуры в `.tmp`) оставляет расхождение навсегда — карточка запускала
`update` при каждом открытии окна и снова показывала «устарел».

Теперь:
- при этом статусе автообновление не запускается;
- главная кнопка — «Пересобрать» (полная сборка), рядом остаётся «Обновить» для дешёвой дельты;
- рядом со статусом объяснение: на диске не тот набор файлов, обновление его не сверит.

## Галочка — это намерение, а не состояние

Флаг читается из параметров проекта (`.dsh/1c-project.json`) отдельным быстрым запросом и не
зависит от проверки свежести. До ответа галочка неактивна и подписана «читаю параметры проекта…»,
а не показывает «выключено».

## Карточка не ждёт проверку свежести

`GET /rlm/index/state` больше не держит ответ, пока CLI обходит дерево: состояние отдаётся из
кэша, устаревшее обновляется в фоне (карточка показывает «проверяю…» и опрашивает состояние).
Таймаут проверки — 60 с вместо 10 с: это проверка (`rlm-bsl-index index info`), а не сборка;
у сборки свой лимит — час. Прогон, убитый по таймауту, больше не читается как «index info
завершился с кодом -1»: пишется «проверка не уложилась в 60 с…», а пустой вывод — «средство
индексации не ответило».

## Папка выгрузки — настройка, а не догадка

Новый ключ параметров проекта `rlmIndexPath`: что индексировать. Пусто — папка проекта.
Поле есть в блоке «Синтаксическая индексация» (окно параметров проекта) и на шаге выгрузки в
визарде; относительный путь считается от папки проекта. Несуществующий путь — отказ с текстом
«папка выгрузки не найдена», а не «индекса нет».

Угадывать раскладку (`src`, `src/cf`) плагин не пытается: вложенность у каждого своя, и путь
знает только человек.

## Один запуск сборки вместо двух

Решение «собрать отсутствующий индекс» принимается в одном месте — по результату проверки.
Раньше два вызова подряд успевали запустить два задания, и второе падало с 409.

## Движок

Установщик каталога ставит `rlm-tools-bsl` 1.47.0 (схема индекса v18). После обновления нужна
полная пересборка: первый `index update` пересобирает индекс целиком.

## Проверки

Новый `test/rlm-index-card.smoke.mjs`: правила автообновления, кнопки «Пересобрать»/«Обновить»,
состояния загрузки галочки. `test/rlm-index.smoke.mjs` дополнен вложенной выгрузкой, быстрым
ответом по флагам и отказом на несуществующий путь.
