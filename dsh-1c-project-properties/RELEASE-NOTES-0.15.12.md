# 0.15.12

## Индекс кода: кнопка «Пересобрать»

В карточке индекса рядом с основной кнопкой стоит «Пересобрать» — полная сборка
с нуля, которая обходит папки и сверяет все файлы `.bsl`, а не только изменения,
известные git. Основная кнопка по-прежнему меняет подпись по состоянию: «Собрать»
без индекса, «Пересобрать» при расхождении состава файлов, «Обновить» в остальных
случаях; при расхождении рядом с ней стоит «Обновить».

## Тост сохранения: зелёная галочка

Отметка успеха в плашке — галочка в круге зелёного цвета, как у тостов
приложения (`IconCheckCircleOutline`), а не символ в цвете текста.
