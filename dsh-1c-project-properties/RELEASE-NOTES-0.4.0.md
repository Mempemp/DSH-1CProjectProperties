# dsh-1c-project-properties v0.4.0

## Новое

- **Вкладка переименована в «1С: Параметры проектов».**
- **Параметры проекта — в отдельном окне.** Раньше форма жила в правом столбце вкладки, а колонка настроек DSH — около 520 px: поля обрезались, подписи ломались, блок выгрузки уезжал под скролл. Теперь вкладка это список проектов, а параметры открываются по клику на проект или по шестерёнке у строки — в модальном окне шириной 760 px с двумя колонками полей.
- **Окно сделано в стиле настроек DSH**: слоистая поверхность `--dsw-alias-bg-layer-2`, маска `--dsw-alias-bg-mask-1`, тень `--dsw-elevation-prominent`, скругление 24 px. Escape закрывает окно и не закрывает сами настройки (перехват на фазе capture), клик по маске тоже закрывает.
- **Строка проекта** показывает название, путь, наличие файла параметров (●/○) и шестерёнку; вкладка отдельной полосой показывает статус выгрузки (проект, время, файлы) с кнопками «Открыть» и «Отменить» — прогресс видно, не открывая окно.
