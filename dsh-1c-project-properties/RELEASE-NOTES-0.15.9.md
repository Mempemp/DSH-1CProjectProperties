# 0.15.9

## Параметры проекта сохраняются целиком

Кнопка «Сохранить» в окне «Параметры проекта» переписывала `.dsh/1c-project.json`
по списку полей подключения. В этот список входили ключи проверок кода, и запись
шла строкой: включённый анализ кода превращался в `""`. Окно после переоткрытия
показывало выключенный анализ, а запуск проверки отказывал словами «статический
анализ выключен в параметрах проекта».

- Форма сохраняет шесть полей подключения: путь к базе, пользователь, пароль,
  путь к платформе, код доступа, каталог выгрузки.
- Ключи `checksEnabled`, `checksPreset`, `rlmIndex`, `rlmIndexPath` и любые другие
  записи файла остаются на месте и с прежним типом.
- Регрессия: `node test/params-persist.smoke.mjs` — включение анализа, сохранение
  формы, повторное чтение состояния и проверка файла после сохранения.
